## 🔥 tech火団とは

tech火団（テッカダン）は、Webエンジニアの有志が集まったサークルです<br>
Webの技術やキャリアについて、本ごとにテーマを決め、そのテーマで書きたい人に声をかけて合同誌をつくっています

### recap: 20代 — 若手に贈る、Webエンジニアの技術とキャリア合同誌

30代前後の6名のエンジニアが、それぞれの20代をふりかえり、若手に伝えたいことを書いた合同誌です<br>
大学3年生〜20代後半の方を主な読者に想定しています

- 小さな貢献が広げた世界
- 20代の自分とエンジニアリング
- お前も技術コミュニティを始めないか
- 20代の経験を振り返る：技術への興味とビジネスへの関わり方の変化
- 役割を変えながら働いてきたエンジニアの、人との向き合い方が変わっていくまで
- homelabへのいざない
